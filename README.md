## This project is a Python-based file encryption and decryption tool that uses AES-256 encryption to protect sensitive files. The application provides a user-friendly graphical interface for secure file handling.

## Features

- AES-256 File Encryption
- Secure File Decryption
- Password-Based Protection
- User-Friendly GUI
- File Selection Dialog
- Error Handling
- Cross-Platform Support

  ## Technologies Used

- Python 3
- Cryptography Library
- Tkinter
- OS Module
